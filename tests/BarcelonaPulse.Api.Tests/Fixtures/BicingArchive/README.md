# Fixtures del histórico de Bicing

Filas inventadas con la cabecera y el formato reales de los archivos mensuales del Ajuntament
(comprobados con agosto de 2026), comprimidas en .7z como los publica el portal. No son datos
reales. Cubren cada caso que trata el adaptador; el detalle, en los comentarios de
`scripts/make-bicing-archive-fixtures.mjs`, que los regenera con bsdtar.
